掲載内容のファクトチェックを行ってください。$ARGUMENTS

## 手順

### 1. まず未確認の記述を一覧する

```
python3 .claude/hooks/factcheck_scan.py report
```

### 2. 範囲を区切る

**一度に全部をやろうとしないこと。** 範囲の指定がなければ、
下の優先順から1〜2グループだけを選んで、今回の対象として最初に宣言してください。

優先順：

1. **生活保護の基準額**（`SEIHO_KIJUN`・`SEIHO_EXAMPLES`・`SEIHO_JUTAKU`・`JUTAKU_FUJO`）
   — 診断結果を直接動かします。**表示用と計算用の2か所が一致しているかも必ず見ること。**
   特例加算は期限付きの措置なので、期限を過ぎていないか確認する
2. **電話番号**（`CONTACTS` の各 `tel`、`TOKUREI.callcenter`）
   — フリーダイヤルや法テラスの番号も含めて、各団体の公式ページで現物照合する
3. **年度で変わる数字**（`AVG_KAKEI` ＝家計調査の前年平均、`RISK_REF.povertyLine` ＝貧困線）
   — 公表のたびに変わります。公表年と調査年を取り違えないこと
4. **掲載時点**（`DATA_ASOF`・`SEIHO_ASOF`・`TOKUREI.asof`・`RISK_REF.asof`）
   — 本文を直したら、対応する時点も直す

### 3. 一次情報と突き合わせる

原典は数字の種類ごとに違います（CLAUDE.md の表を参照）。

- **まとめサイト・他自治体のページ・検索結果のスニペットだけでは根拠にしない。**
  数字はページ本文で現物照合する。
- 確認できた値は `docs/fact-log.md` に出典URLと確認日つきで追記する。
  表示用と計算用の2か所あるものは、2行に分けて記録する。
- 新しい改定が見つかったら、本文と該当する時点の両方を直す。
  基準額を直したら `SEIHO_EXAMPLES` の計算例も計算し直す。
- 確認できなかったものは**推測で埋めず**、本文に `【要確認】` を付ける。
- ネットに繋がらないときは、確認できなかったものとして扱う。
- `THRESHOLDS`・`GUIDELINES` は当ツール独自の目安です。出典を探しても
  見つからないのが正常なので、**公的基準として書き換えないこと。**

### 4. 報告は3つに分けて書く

- **✅ 確認して正しかったもの** … 項目／値／出典URL
- **🔧 誤りを修正したもの** … 項目／旧値 → 新値／出典URL
- **⚠️ 確認できず `【要確認】` にしたもの** … 項目／なぜ確認できなかったか

今回見ていない範囲があれば、最後に「次回の対象」として書き添えてください。
